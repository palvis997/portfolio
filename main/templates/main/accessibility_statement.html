Our Commitment to Universal Access

Pavis Mugo Muruga is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards including the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA principles.

Built-in Accessibility Features & Tools

Full Keyboard Navigation

Every interactive element, button, navigation link, form field, and modal can be fully operated using standard keyboard keys (Tab, Enter, Space, Esc).

Controlled Text Sizing

The floating Accessibility Bar provides A-, A, and A+ font scaling (80% to 130%) without breaking visual layouts or truncating text.

High Contrast Mode

A dedicated high-contrast mode increases foreground-to-background color separation and reinforces crisp component borders for maximum legibility.

Dyslexia-Friendly Typography

Optional typography switch to *Atkinson Hyperlegible* and *Lexend* with widened letter-spacing and optimized line-height for enhanced reading comprehension.

Reduced Motion & Animations

Disables decorative background floaters, keyframe animations, and smooth scrolling for visitors with vestibular disorders, respecting OS preferences.
